# Start Here

This folder is a white-label Skillz + Second-Brain deployment package.

Do **not** operate directly from the source owner's shared package.

## 1. Claim the package

Copy/import this complete deployment into a Google Drive location owned by you or your organization. **Do not use the GitHub distribution checkout as the claimed runtime store.**

## 2. Rebind

Resolve the copied package's new Drive folder/file IDs, including the tenant Deliveries root, and update the tenant instance configuration.

Provider IDs from the source package are not canonical after copying.

## 3. Validate

Follow `handoff/VALIDATION.md`.

Do not start adding private knowledge until integrity, ownership and privacy checks pass.

## 4. Install the system-prompt hook

Use the rendered bootstrap locator from your claimed instance.

## 5. Create your first real Child Brain

Start with an empty federation. Create and register a Child Brain only when a durable project or domain scope exists.

Your instance is successfully handed off when it operates without source-owner Drive access and generated non-code artifacts are written to recipient-owned Drive and returned by verified Drive links.
