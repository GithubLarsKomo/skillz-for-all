# Claim Procedure

1. Copy/import the full package into recipient-owned Google Drive.
2. Record the new deployment root folder ID.
3. Resolve new IDs for framework and Super Second Brain roots.
4. Render tenant `instance.yaml` from the recipient values.
5. Replace package placeholders with recipient-owned locators where rendering is required.
6. Do not carry source-owner Drive IDs into active tenant state.
7. Read back the rendered instance configuration.
8. Continue with `VALIDATION.md`.

A shared folder owned by the sender is not a completed claim.
