# Authoritative source routing – Trade, sanctions & export control

Discovery baseline verified 2026-08-28. Runtime re-check via `current-law-context` is mandatory.

- Außenwirtschaftsgesetz (AWG), current German official text.
- Außenwirtschaftsverordnung (AWV), current German official text and current annexes.
- Regulation (EU) 2021/821 on dual-use export, brokering, technical assistance, transit and transfer, using the current consolidated version and annexes.
- Current EU sanctions regulations, consolidated lists and competent-authority guidance for the specific country/person/sector.
- BAFA official licensing/classification guidance and decisions where available.
- Technical product/technology classification evidence, end-use statements, ownership/control evidence and transaction records.

Lists, annexes, sanctions and licensing rules are time-sensitive. Never clear a transaction solely from a stale screening screenshot or a historic classification.
