# Authoritative source routing – IP / Licensing

Discovery baseline verified 2026-08-28. Runtime re-check via `current-law-context` is mandatory.

- Patentgesetz (PatG), especially § 15 for transfer/licensing and triggered provisions on scope/enforcement.
- Urheberrechtsgesetz (UrhG), especially §§ 31, 34 and triggered remuneration/transfer rules.
- Gesetz über Arbeitnehmererfindungen (ArbnErfG), especially §§ 5–8 and compensation rules where triggered.
- MarkenG, GeschGehG and other IP statutes when the relevant asset type is present.
- Current registers, assignments, invention reports, employment/consultancy agreements, license agreements and prosecution records for chain-of-title evidence.
- EU competition rules and applicable block-exemption/guidance only via current competition-law analysis; no static assumption that an IP restriction is exempt.

Patent landscape, technical claim mapping and FTO screening remain owned by the existing patent/biopatent/FTO skills; legal opinions on claim construction, validity, enforceability or launch FTO require Patent Counsel when material.
